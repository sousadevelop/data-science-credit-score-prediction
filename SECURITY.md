# Security and Data Handling

## Educational Scope

This repository documents a fictional credit score classification case for learning purposes. It is not a production credit decision system.

## Data Care

- Do not add real customer records, personal documents, credentials, or private exports.
- Treat identifiers and financial attributes as potentially sensitive even in educational datasets.
- Keep screenshots free of personal data.
- Review datasets before publishing changes.
- Do not use the notebook as the sole basis for decisions that affect real people.

## Model Governance

A production system would require privacy review, lawful basis assessment, bias evaluation, explainability, monitoring, access controls, reproducibility, and human oversight. Those controls are outside the scope of this educational repository.

## Reporting

When reporting a concern, avoid publishing sensitive data in public issues. Use a private GitHub security advisory when appropriate.
