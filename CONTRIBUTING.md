# Contributing

## Principles

- Preserve the educational nature of the project.
- Do not add real customer data or sensitive information.
- Do not change analytical conclusions without documenting the evidence.
- Keep notebook, report, and documentation aligned.
- Add context and captions when contributing images.
- Separate documentation improvements from model changes.

## Pull Request Checklist

- [ ] No sensitive data was introduced.
- [ ] Existing datasets and notebook outputs were preserved or changes were explicitly explained.
- [ ] Images include clear purpose and interpretation.
- [ ] Dependencies are documented.
- [ ] Relevant validation was run.
